📚 Fontes de estudo — Segundo Cérebro de Programação

Este documento reúne as principais fontes utilizadas na construção do segundo cérebro digital sobre desenvolvimento de aplicações web modernas com Inteligência Artificial.

A prioridade é dada às documentações oficiais e aos materiais técnicos confiáveis. As respostas produzidas por ferramentas de IA devem ser verificadas nas fontes sempre que possível.

1. HTML, CSS e JavaScript

Fonte: MDN Web Docs

Link: https://developer.mozilla.org/pt-BR/

Utilização: estudar os fundamentos da web, linguagens de programação, acessibilidade, APIs e boas práticas para páginas e aplicações web.

2. React

Fonte: Documentação oficial do React

Link: https://react.dev/learn

Utilização: compreender componentes, propriedades, eventos, estado e construção de interfaces.

3. TypeScript

Fonte: Manual oficial do TypeScript

Link: https://www.typescriptlang.org/docs/handbook/intro.html

Utilização: estudar tipagem, organização do código e recursos que ajudam a identificar erros durante o desenvolvimento.

4. GitHub

Fonte: Documentação oficial do GitHub

Link: https://docs.github.com/pt

Utilização: aprender sobre repositórios, versionamento, colaboração, documentação e publicação de projetos.

5. Supabase

Fonte: Documentação oficial do Supabase

Link: https://supabase.com/docs

Utilização: estudar bancos de dados PostgreSQL, autenticação, armazenamento e recursos de backend.

6. Vercel

Fonte: Documentação oficial da Vercel

Link: https://vercel.com/docs

Utilização: compreender a publicação de aplicações, ambientes de implantação e processos de desenvolvimento e produção.

7. Segurança de aplicações web

Fonte: OWASP Top 10

Link: https://owasp.org/www-project-top-ten/

Utilização: conhecer riscos comuns de segurança em aplicações web e aprender a considerar práticas de proteção durante o desenvolvimento.

8. Inteligência Artificial aplicada à programação

Fonte: Documentação oficial do GitHub Copilot

Link: https://docs.github.com/en/copilot

Utilização: estudar formas de utilizar IA como apoio à escrita, compreensão e revisão de código, considerando suas limitações.

9. Programação com IA — conteúdo educacional

Fonte: freeCodeCamp — Learn to Code using AI

Link: https://www.youtube.com/watch?v=dJhlMn2otxA

Utilização: complementar os estudos com exemplos práticos de programação assistida por IA.

10. Agentes de codificação

Fonte: GitHub — Introducing the GitHub Copilot coding agent

Link: https://www.youtube.com/watch?v=EPyyyB23NUU

Utilização: conhecer o conceito de agentes de codificação e sua participação nos fluxos de desenvolvimento de software.

11. Agent Skills

Fonte: Anthropic — Skills e desenvolvimento de agentes

Links:

- https://www.anthropic.com/research/skills
- https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- https://base44.com/

Utilização: estudar como instruções e habilidades reutilizáveis podem especializar agentes de IA para tarefas específicas. O tema também se relaciona à criação de fluxos de trabalho para ferramentas de desenvolvimento, como Claude Code, Lovable e Base44.

📌 Critérios de utilização das fontes

- Priorizar documentações oficiais e materiais técnicos confiáveis.
- Conferir se as informações continuam atualizadas.
- Utilizar citações ou referências do NotebookLM para verificar as respostas.
- Separar informações encontradas nas fontes de interpretações e sugestões.
- Não confiar cegamente em respostas ou códigos gerados por IA.

🎯 Finalidade

Organizar as referências utilizadas no projeto, facilitar consultas futuras e apoiar o desenvolvimento de autonomia técnica em programação, desenvolvimento web e Inteligência Artificial.

---

Observação: esta lista registra as fontes selecionadas para o projeto. A inclusão de uma referência não significa que todo o seu conteúdo tenha sido estudado integralmente.
