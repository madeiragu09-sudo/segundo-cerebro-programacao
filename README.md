🧠 Segundo Cérebro de Programação — Desenvolvimento Web com IA

📌 Sobre o projeto

Este projeto faz parte de uma jornada de aprendizagem voltada ao desenvolvimento de aplicações web modernas com Inteligência Artificial.

A proposta é criar um segundo cérebro digital utilizando o NotebookLM, reunindo fontes confiáveis e organizando conhecimentos técnicos para facilitar os estudos, a resolução de dúvidas e o desenvolvimento de projetos práticos.

🎯 Objetivo

Criar um assistente de estudos especializado em desenvolvimento web, capaz de explicar conceitos de programação, apoiar decisões técnicas e ajudar na compreensão de ferramentas de Inteligência Artificial com base em fontes selecionadas.

📚 Principais temas estudados

- HTML, CSS e JavaScript;
- TypeScript e React;
- Git e GitHub;
- Supabase e bancos de dados;
- Vercel e publicação de aplicações;
- Segurança de aplicações web e OWASP Top 10;
- Inteligência Artificial aplicada à programação;
- Agentes de codificação e Agent Skills;
- Testes, acessibilidade, desempenho e boas práticas de desenvolvimento.

🛠️ Ferramentas utilizadas

- NotebookLM: organização e consulta das fontes de estudo.
- GitHub: versionamento e documentação pública do projeto.
- Inteligência Artificial: apoio à aprendizagem e à análise de conceitos técnicos.

🔎 Metodologia

1. Selecionar fontes técnicas e documentações relevantes.
2. Organizar as fontes no NotebookLM.
3. Configurar instruções para orientar o assistente de estudos.
4. Fazer perguntas sobre os principais temas.
5. Conferir as respostas e suas referências.
6. Produzir materiais de estudo e documentar os resultados.

📄 Material de estudo

O repositório contém um guia de estudos em PDF sobre desenvolvimento web moderno com Inteligência Artificial.

Consulte os arquivos disponíveis neste repositório para acessar o material.

🚀 Aprendizados esperados

- Compreender melhor os fundamentos do desenvolvimento web.
- Aprender a consultar documentações técnicas.
- Utilizar ferramentas de IA de maneira crítica e responsável.
- Verificar respostas e códigos em vez de confiar cegamente na IA.
- Desenvolver autonomia para estudar, testar e construir aplicações.

🔐 Compromisso com boas práticas

O projeto valoriza a segurança, a acessibilidade, a validação de código, a consulta a fontes confiáveis e a compreensão das decisões técnicas.

A Inteligência Artificial é utilizada como ferramenta de apoio à aprendizagem, e suas respostas devem ser verificadas.
